# 300-Episode 分析文件

这些文件均为已有运行的原始文件副本：

- `coverage.json`、`coverage_cells.csv`、`coverage.md`：mixed VLN half 的最终 coverage 报告，来源为 `coverage/mixed_20260713_135529/`。
- `summary.json`：3000 条混合 VLN/IDS 数据的构建摘要。
- `episodes.csv`：Oracle 的 300 个 episode 结果，301 行包含 1 行表头。
- `DATA_READINESS.md`：整套数据准备状态与结果边界。
- `dataset_report.json`：300 train / 60 scene-disjoint validation episodes 的数据集说明。

关键边界：这是 HM3D engineering protocol，不是 R2R/RxR benchmark。
