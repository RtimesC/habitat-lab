# YOLO Archive

This folder contains the old YOLO-based navigation baseline and its generated
artifacts. It is kept only for reference and is not part of the active VLM
navigation route.

Contents:

- `scripts/habitat_yolo_nav.py`: YOLO + rule-based navigation baseline.
- `scripts/sample_start_views.py`: YOLO-assisted start-view sampler.
- `models/yolov8n.pt`: YOLOv8 Nano weights used by the old scripts.
- `outputs/`: old YOLO frames, videos, trajectory files, and sampled start views.
