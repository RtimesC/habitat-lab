# Habitat 仿真与离线评测平台定位

## 目的

本仓库服务于团队的 VLN 仿真实验和离线评测。它的任务是提供可重复的 Habitat-Sim 场景、任务适配、观测/动作接口、baseline、指标计算和实验产物记录。

它不承担 VLN 主策略的长期研究迭代，也不替代独立算法仓库。

## 当前研究入口

当前仿真主线是：

```text
Habitat-HM3D 场景
    -> VLN 任务适配器
    -> 原始观测与动作空间复现
    -> baseline smoke test
    -> 短评测与指标核对
    -> 研究方法实验
```

第一阶段优先完成论文原始任务和动作空间复现。只有任务契约、动作定义、数据 split 和指标闭环稳定后，才加入 3DGS、空间记忆或其他研究模块。

## 目录职责

### 上游平台层：保持稳定

- `habitat-lab/`：Habitat-Lab 核心库；
- `habitat-baselines/`：上游 baseline 和训练组件；
- `habitat-hitl/`：人机协同与交互支持；
- `habitat/`：Habitat-Lab 的核心 Python 包；
- `examples/`：上游示例和最小验证脚本。

除非实验明确需要，不在这些目录中加入团队特定的 VLN 逻辑。

### 团队仿真实验层：`habitat_vln/`

`habitat_vln/` 是本团队在本仓库中的仿真与离线评测层，负责：

- HM3D/VLN 任务配置和数据适配；
- RGB/RGB-D、动作历史和动作空间的任务契约；
- 原始论文任务与动作空间复现；
- 仿真 baseline 和 smoke test；
- 轨迹、视频、指标和失败案例记录；
- 后续 3DGS、空间记忆和连续控制适配实验。

这里的代码必须说明自己的实验角色，不能被表述为 Habitat-Lab 官方功能。

### 研究文档层：`docs/research/`

用于保存：

- 仿真平台定位；
- 任务契约；
- HM3D 数据和 split 说明；
- 复现实验记录；
- 指标定义和结果审计说明；
- 研究方向与平台边界。

### 实验产物层

实验输出应放到明确的实验目录，至少区分：

- 配置快照；
- episode/trajectory 日志；
- 视频和帧；
- 指标汇总；
- 失败分析；
- 复现报告。

不覆盖历史结果，不把临时调试文件混入正式结果目录。

## 仿真平台要解决什么

1. **任务是否定义正确**：语言指令、场景、episode、split 和终止条件可核对；
2. **动作是否定义正确**：原始论文动作、waypoint、回溯和 STOP 行为可解释；
3. **观测是否真实**：策略只获得任务允许的 RGB/RGB-D、历史和局部可观测信息；
4. **实验是否可重复**：配置、随机种子、版本和日志完整保存；
5. **结论是否可审计**：指标、失败原因和数据来源能够回溯。

## 仿真平台不解决什么

- 不把 Habitat 仿真代码变成 VLN 主算法库；
- 不把 PointNav 的目标坐标、最短路径或成功信号注入 VLN 策略；
- 不用 Oracle、隐藏终点或评价真值替代模型决策；
- 不在没有任务契约的情况下批量下载 HM3D 或运行长时间仿真；
- 不把仿真成功直接表述为真实小车部署成功；
- 不在本阶段同时解决校园室外、跨楼宇和真实底盘控制。

## 当前重构顺序

1. 保持官方 Habitat 目录不动；
2. 为 `habitat_vln/` 建立清晰 README 和模块职责说明；
3. 先完成 HM3D/VLN 原始任务与动作空间复现；
4. 将旧 PointNav、NaVIDA、Mock 和历史代码明确标注为 active、supporting 或 legacy；
5. 为每个实验建立独立配置和结果目录；
6. 复现闭环稳定后，再接入两个研究方向：`3dgs-vln` 和 `spatial-intelligence-reasoning`。

## 完成标准

当以下内容可独立复现时，仿真平台第一阶段完成：

- HM3D 场景和 VLN episode 可以加载；
- RGB/RGB-D 观测字段和动作空间有文档与 smoke test；
- 原始任务可以 reset、step、STOP 和记录轨迹；
- baseline 指标可以计算；
- 论文原始 benchmark 与 HM3D 适配差异有记录；
- 没有目标坐标、最短路径、Nav2 路径或 SLAM 位姿泄漏到主策略；
- 结果和失败分析可以追溯到配置、episode 和代码版本。
